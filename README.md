# 訪問介護予定表 自動作成システム（デモ版）

訪問介護の週間訪問予定を自動で作成・確認・修正するWebアプリのデモです。
報告・説明用に公開しているもので、**表示されている氏名・部屋番号はすべて架空の値**です。
実際の利用者情報は含まれていません。

## デモを開く

👉 https://ginshoen.github.io/helper-schedule-demo/

ブラウザだけで動作します。インストールやログインは不要です。

## 画面の流れ

1. **取り込む** — 利用者・職員・勤務表・曜日別予定をアプリに読み込む
2. **自動作成** — 対象の月（または日）を選ぶと訪問予定を自動生成
3. **確認して確定** — 内容を確認し、問題なければ確定

## 自動作成で考慮していること

- 職員ごとの「訪問できない利用者」（NG設定）
- 日曜出勤の可否
- 時刻が決まっている固定訪問の優先確保
- 同じ職員の時間重複を作らない
- 外訪問の移動時間の確保
- 職員間の訪問件数の平準化

## 主な画面

| 画面 | 内容 |
| --- | --- |
| ダッシュボード | 当日の訪問件数・警告・職員別タイムライン |
| 自動作成 | 取込 → 作成 → 確認 → 確定の4ステップ |
| 日別 | 期間を指定して予定を一覧・修正・印刷 |
| 未割当 | 担当が決まらない訪問と、その理由・代替候補 |
| マスタ | 利用者・職員・サービス予定の一覧 |
| 出力 | CSV・日別PDF・Excel出力 |

## 補足

- データの取り違えや登録漏れは「確認事項」として画面に表示されます
- 職員の勤務時間は暫定値（8:00〜17:30）で計算しています
- このデモはサーバー通信部をモックで動かしており、単体で完結します
